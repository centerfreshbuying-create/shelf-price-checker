Browser helper

Evergreen, Gourmet Glatt, NPGS, Foodex, Glatt Mart, Kosher Corner, Pomegranate and Shop Smart only open in a real browser. The Price Checker helper is a small Chrome add-on that searches them for you in a background window, so their prices show up with all the other stores.

Download the helper
  1. Unzip the download.
  2. In Chrome, go to chrome://extensions and turn on Developer mode (top right).
  3. Click Load unpacked and pick the unzipped price-checker-helper folder.
  4. Reload this page. The line above turns green.

Adding a store

Paste the store's website. If it runs on My Cloud Grocer or Shopify, the checker finds its product search by itself and checks prices automatically. Use Run test in the store form to see it work before you save.

For other sites, use the store's search link: search for any item on their site, copy the address of the results page, and replace your search words with {barcode} (or {name} for sites that only search by name).

Some sites turn automated checks away. Those stores are marked "Prices by hand": their tag has an Open button to look the price up, and you type it in.
